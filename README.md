# Node-Notas

## Descripción
Este proyecto consiste en construir una API RESTful para almacenar notas por usuarios. La API es capaz de realizar operaciones CRUD (Crear, Leer, Actualizar y Eliminar) sobre una lista de notas. Se usa MongoDB (base de datos no relacional).

## Detalles de desarrollo
El stack tecnológico utilizado es Node.js y React. Para consultar información más detallada sobre la arquitectura e implementación, revise la [documentación principal](./documents/Principal.md).

## Configuración del entorno

1. Copia el archivo `.env.example` y renómbralo como `.env`:
   ```bash
   cp .env.example .env
   ```
